# Beginner glossary

[← Home](https://github.com/YukiUmetsu/kumiki-blender/wiki)

You do not need to memorize these words. Come back here whenever you see an unfamiliar term.

| Word | Meaning |
| --- | --- |
| **3D model** | A digital object with width, height and depth |
| **Mesh** | A surface made from connected points, edges and faces, like a flexible wire frame covered in panels |
| **Vertex / vertices** | One point / multiple points on a mesh |
| **Polygon / face** | A flat surface section between mesh points |
| **Material** | A description of how a surface looks, such as red paint, dull stone or metal |
| **Texture** | An image or data map used to add color, fine detail or surface variation |
| **PBR** | Physically Based Rendering: materials defined by properties such as base color, roughness and normal maps |
| **Normal map** | An image that makes small bumps appear in lighting without adding corresponding physical geometry |
| **Geometry** | The actual 3D shape and physical structure of a model |
| **Scene** | A collection of models, lights and cameras |
| **Camera** | The viewpoint from which a picture or animation is rendered |
| **Render** | The process of producing a 2D image from a 3D scene |
| **Viewport** | The interactive 3D area inside Blender where you move your view |
| **Blender** | Free application for making, editing, rendering and animating 3D scenes |
| **GLB** | Portable binary glTF model file; can include geometry, materials, textures and animation |
| **Blend file** | Blender's native editable project file (`.blend`) |
| **Recipe** | A JSON file describing model parameters such as dimensions and color |
| **Catalog** | The list of available model families and their build instructions |
| **Rig / rigging** | Movable controls or skeleton relationships that let parts animate |
| **Revision** | One immutable output version, such as `r01` or `r02` |
| **CLI** | Command-line interface: a tool you run by typing commands in Terminal or PowerShell |
| **Python** | Programming language used to validate recipes and generate models in this project |
| **JSON** | Simple text format for named settings, using `{}`, quotes, commas and values |
| **Provenance** | A record of where an asset came from and what rights or evidence support its use |
| **Photogrammetry** | Reconstructing 3D shape or camera positions from multiple overlapping photographs |
| **Silhouette** | Outer outline of an object as seen from one viewpoint |
| **QA** | Quality assurance: checks, visual reviews and comparisons used to catch errors |

Want to practice the words? Go back to [Start Here](https://github.com/YukiUmetsu/kumiki-blender/wiki/Start-Here) and [Make Your First 3D Model](https://github.com/YukiUmetsu/kumiki-blender/wiki/Make-Your-First-3D-Model).
